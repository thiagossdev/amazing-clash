# Path of Exile 2 Build-Depth Research

Deep-research reference on Path of Exile 2's character-building systems
(shared passive tree, skill-gem/support-gem design, weapon-swap dual
specialization, itemization philosophy), gathered as the second of two
inspiration pillars for AmazingClash: a real-time, one-fighter-per-
player PvP arena combat game the human owner wants built with the same
depth of character customization as Path of Exile 2. The first pillar,
the game's structural and combat-feel inspiration, lives in the sibling
folder `docs/research/eslabong-inspiration/`.

This folder is scoped narrowly to *build-depth mechanisms*, not a
general Path of Exile 2 design study: PoE2's campaign structure, loot
economy pacing, and monetization are out of scope, since none of them
transfer to a session-based competitive PvP game. Read
[5. Synthesis](05-synthesis-amazingclash.md) for where this pillar
combines with
[eslabong-inspiration/05](../eslabong-inspiration/05-synthesis-amazingclash.md)
into this project's proposed design direction.

## Confidence Notes

Two of three directly-cited sources are press pieces built on direct,
attributed developer quotes (PC Gamer, PCGamesN), not GGG's own
first-party blog posts; one is a community mechanical guide treated at
the same canonical tier this project's sibling research gave Fandom
wikis. A handful of specific figures (total node count, base passive
point count, the 12-class/9-slot/5-link gem structure) come from
search-engine synthesis across multiple community guides rather than a
direct fetch, and are flagged as such wherever they appear. See
[Sources](sources.md) for the full breakdown and for why a deeper pass
reading GGG's own manifesto posts directly would strengthen this folder
further if build depth becomes an active development focus.
